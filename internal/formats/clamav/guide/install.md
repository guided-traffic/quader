Run `freshclam` once. On an empty database directory it fetches each database whole with its detached signature and checks both; it reports `daily.cvd updated` for each. A second run reports `daily.cvd database is up-to-date` and costs one request of 512 bytes per database. After that, `freshclam` checks as often as `Checks` says, 12 times a day by default, and fetches a database only when Quader's set in use has a newer version.
